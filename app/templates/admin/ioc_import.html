Import IOCs from a start_ioc script

Paste your start_ioc script, or just its IOCLIST table. Each NAME PORT ONBOOT COMMAND line becomes a procServ-managed soft IOC: status = procServ on that port with a live IOC process, start = <script> -s NAME, stop = kill that procServ. IOCs already present (same host and name or same procServ port) are skipped, so re-importing is safe.

If the watchdog runs as a systemd service, use this machine's hostname, not localhost, so the IOCs survive service restarts.
